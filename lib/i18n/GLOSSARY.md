# Lab World glossary (German → English)

Use these English terms everywhere so the game reads consistently. Item and device
names are shown in-game; keep them exactly as listed. Codes, bot names (F1N-DR,
C8-BR41N …), device ids (MCP-000, UEC-001) and `_unOS`/`_unSLC` stay unchanged.

## People & voice

- Jade Lawrence = "Dr. Lawrence" (player, she/her), Damien Fridge = "Damien" / "Dr. Fridge".
- The MCP is formal and dryly bureaucratic ("Dr. Lawrence", never casual).
- UI and handbook address the player directly ("you"), short and clear.
- Keep the humour dry; don't add jokes that aren't in the German.
