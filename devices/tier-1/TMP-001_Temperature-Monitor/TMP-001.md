## Description

Multi-sensor temperature monitoring device that tracks thermal conditions across the laboratory using distributed thermal probes. The Temperature Monitor provides threshold-based alerting, cooling system status monitoring, and automatic sensor calibration. It feeds temperature data to the THM-001 Thermal Manager for coordinated thermal management responses.

## Terminal Command

```

```

**Aliases**: `temperature`

### Subcommands

- `status` — Show temperature readings across all sensors
- `firmware` — Show firmware version and feature list
- `test` — Run sensor calibration diagnostics
- `config` — View or modify temperature thresholds and alerts
- `reboot` — Restart temperature monitor controller
- `fold` — Collapse device panel
- `unfold` — Expand device panel
- `toggle` — Toggle device panel visibility
