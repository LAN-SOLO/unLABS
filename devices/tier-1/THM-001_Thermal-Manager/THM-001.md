## Description

System-level thermal management controller responsible for monitoring and regulating temperature across all laboratory thermal zones. The Thermal Manager oversees CPU, GPU, and PANEL thermal zones, coordinating fan speeds, cooling responses, and emergency thermal shutdowns. It works in conjunction with TMP-001 (Temperature Monitor) for sensor data and VNT-001 (Ventilation System) for active cooling.

## Firmware

No firmware file — device has no dedicated manager context with firmware export. Thermal management logic is handled at the system level within `ThermalManager.tsx`.

## Power Specifications

Device operates as the master thermal controller with no self-reported power draw.

- **Status**: Always ONLINE

## Terminal Command

```
thermal [status|fan|auto|emergency]
```

**Aliases**: `therm`, `temp`, `cooling`

### Subcommands

- `status` — Show thermal zone temperatures and fan states
- `fan` — Manual fan speed control
- `auto` — Enable/disable automatic thermal management
- `emergency` — Trigger emergency cooling protocol

## Thermal Zones

- **CPU** — Processor thermal zone
- **GPU** — Graphics processor thermal zone
- **PANEL** — Panel/display thermal zone

## Device States
