## Description

Real-time processor monitoring device that tracks CPU utilization, core frequencies, cache performance, and thermal conditions across all processing units in the laboratory. The CPU Monitor supports multi-core monitoring, dynamic frequency scaling observation, thermal link integration with the THM-001 Thermal Manager, cache analysis, and built-in stress testing capabilities.

## Terminal Command

```
cpu <status|firmware|test|config|reboot|fold|unfold|toggle>
```

**Aliases**: `processor`

### Subcommands

- `status` — Show CPU utilization, frequencies, and core states
- `firmware` — Show firmware version and feature list
- `test` — Run CPU diagnostics and stress tests
- `config` — View or modify monitor configuration
- `reboot` — Restart CPU monitor controller
- `fold` — Collapse device panel
- `unfold` — Expand device panel
- `toggle` — Toggle device panel visibility
