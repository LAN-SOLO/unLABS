## Description

Precision material analysis instrument capable of identifying material compositions, detecting anomalies, and performing sweep scans across crystal samples and laboratory components. The Material Scanner provides the foundation for quality control, resource identification, and anomaly detection in the fabrication pipeline.

## Terminal Command

```
msc <status|firmware|test|config|reboot>
```

**Aliases**: `scanner`, `matscan`

### Subcommands

- `status` — Show scanner status and last scan results
- `firmware` — Show firmware version and feature list
- `test` — Run scanner calibration diagnostics
- `config` — View or modify scanner configuration
- `reboot` — Restart scanner controller
