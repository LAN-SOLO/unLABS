## Description

Standard-issue laboratory toolkit containing essential instruments for crystal analysis, component assembly, and general maintenance. The Basic Toolkit houses four primary tools — probe, clamp, laser, and drill — each with dedicated firmware-controlled feedback systems for precision operation.

## Terminal Command

```
btk <status|firmware|test|config|tools|reboot>
```

**Aliases**: `toolkit`

### Subcommands

- `status` — Show toolkit status and tool readiness
- `firmware` — Show firmware version and feature list
- `test` — Run tool diagnostics
- `config` — View or modify toolkit configuration
- `tools` — List available tools and their states
- `reboot` — Restart toolkit controller
