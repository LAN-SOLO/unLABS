## Description

Active air circulation and environmental control system featuring dual fans, HEPA filtration, humidity control, and motorized damper management. The Ventilation System works in coordination with the THM-001 Thermal Manager and TMP-001 Temperature Monitor to maintain optimal laboratory environmental conditions. It provides configurable fan speeds, air exchange rate monitoring, and filter status tracking.

## Terminal Command

```

```

**Aliases**: `vent`, `ventilation`, `fan`, `vnt001`, `cooling`

### Subcommands

- `status` — Show ventilation status, fan speeds, and air quality
- `power` — Display power consumption details
- `firmware` — Show firmware version and feature list
- `test` — Run fan and filter diagnostics
- `reset` — Reset ventilation controller
- `fan` — Adjust fan speed and mode
- `fold` — Collapse device panel
- `unfold` — Expand device panel
- `toggle` — Toggle device panel visibility
- `info` — Display detailed device information
