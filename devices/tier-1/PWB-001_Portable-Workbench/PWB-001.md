## Description

Configurable assembly workstation with multiple tool slots for crystal fabrication, component assembly, and maintenance operations. The Portable Workbench manages slot allocation, tool tracking, automatic calibration, and assembly queue scheduling. It serves as the primary hands-on workspace for laboratory operations requiring physical manipulation of crystals and components.

## Terminal Command

```
pwb <status|firmware|test|config|slots|reboot|fold|unfold|toggle>
```

**Aliases**: `workbench`, `bench`

### Subcommands

- `status` — Show workbench status and slot occupancy
- `firmware` — Show firmware version and feature list
- `test` — Run workbench calibration diagnostics
- `config` — View or modify workbench configuration
- `slots` — List tool slots and their contents
- `reboot` — Restart workbench controller
- `fold` — Collapse device panel
- `unfold` — Expand device panel
- `toggle` — Toggle device panel visibility
