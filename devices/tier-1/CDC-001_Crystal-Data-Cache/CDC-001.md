## Description

Crystalline data storage for research archives. The Crystal Data Cache indexes crystal (\_unITM) and slice (\_unSLC) data from the blockchain, maintaining a local synchronized copy of all crystal metadata, trait information, and slice compositions. It serves as the primary data layer between on-chain crystal state and the laboratory's local processing systems.

## Terminal Command

```
cdc [status|power|firmware|test|reset|fold|unfold|toggle|info]
```

**Aliases**: `cache`, `crystalcache`

### Subcommands

- `status` — Show cache status, sync state, and index statistics
- `power` — Display power consumption details
- `firmware` — Show firmware version and feature list
- `test` — Run cache integrity diagnostics
- `reset` — Reset cache and re-index from blockchain
- `fold` — Collapse device panel
- `unfold` — Expand device panel
- `toggle` — Toggle device panel visibility
- `info` — Display detailed device information
