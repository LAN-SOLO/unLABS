## Description

Rechargeable energy storage unit for the laboratory power grid. The Battery Pack provides backup power capacity and energy buffering for all connected devices. It features cell-level monitoring, automatic regeneration cycles, capacity tracking, thermal protection, and CDC handshake protocol for data synchronization with the Crystal Data Cache.

## Terminal Command

```
bat [status|power|firmware|test|reset|fold|unfold|toggle|info]
```

**Aliases**: `battery`, `pack`, `batterypack`

### Subcommands

- `status` — Show battery status, charge level, and cell health
- `power` — Display power input/output statistics
- `firmware` — Show firmware version and feature list
- `test` — Run battery diagnostics and cell tests
- `reset` — Reset battery controller
- `fold` — Collapse device panel
- `unfold` — Expand device panel
- `toggle` — Toggle device panel visibility
- `info` — Display detailed device information
