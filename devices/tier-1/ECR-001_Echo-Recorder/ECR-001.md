## Description

Blockchain signal receiver and decoder that captures on-chain data feeds, rotation tracking events, and oracle synchronization signals. The Echo Recorder acts as the laboratory's primary blockchain listener, translating raw chain activity into usable data streams for other devices. It features a tunable knob interface for signal selection and a ticker-tape output for continuous feed monitoring.

## Terminal Command

```
ecr [status|power|firmware|test|reset|record|knob|fold|unfold|toggle|info]
```

**Aliases**: `echo-recorder`, `ecr001`

### Subcommands

- `status` — Show recorder status and active feeds
- `power` — Display power consumption details
- `firmware` — Show firmware version and feature list
- `test` — Run signal reception diagnostics
- `reset` — Reset recorder and clear buffers
- `record` — Start/stop recording blockchain signals
- `knob` — Adjust signal tuning knob
- `fold` — Collapse device panel
- `unfold` — Expand device panel
- `toggle` — Toggle device panel visibility
- `info` — Display detailed device information
