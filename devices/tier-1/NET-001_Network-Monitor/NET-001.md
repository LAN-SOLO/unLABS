## Description

Comprehensive network monitoring device that tracks NIC status, DHCP configuration, throughput metrics, latency measurements, and packet inspection across all laboratory network interfaces. The Network Monitor provides real-time visibility into the lab's communication infrastructure, supporting both local device-to-device networking and external blockchain connectivity.

### Features

- `nic-detect` — Network interface card detection and enumeration
- `dhcp-client` — DHCP client for automatic IP configuration
- `throughput-monitor` — Real-time throughput measurement and graphing
- `latency-track` — Latency tracking and jitter analysis
- `packet-inspect` — Packet inspection and protocol analysis

## Terminal Command

```
net <status|firmware|test|config|reboot|fold|unfold|toggle>
```

**Aliases**: `network`, `netmon`

### Subcommands

- `status` — Show network interfaces, throughput, and latency
- `firmware` — Show firmware version and feature list
- `test` — Run network diagnostics and connectivity tests
- `config` — View or modify network configuration
- `reboot` — Restart network monitor controller
- `fold` — Collapse device panel
- `unfold` — Expand device panel
- `toggle` — Toggle device panel visibility
