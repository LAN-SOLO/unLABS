## Description

Real-time memory subsystem monitor that tracks DIMM module status, SPD configuration, memory timings, and bandwidth utilization across the laboratory's compute infrastructure. The Memory Monitor supports multiple display modes and provides comprehensive diagnostics for memory health, performance, and configuration validation.

### Features

- `dimm-detect` — Automatic DIMM module detection and identification
- `spd-read` — Serial Presence Detect (SPD) data reading
- `timing-config` — Memory timing configuration and validation
- `bandwidth-test` — Memory bandwidth benchmarking
- `multi-mode` — Multiple display modes for different monitoring views

## Terminal Command

```
mem [status|firmware|test|config|mode|reboot|fold|unfold|toggle]
```

**Aliases**: `memory`, `ram`

### Subcommands

- `status` — Show memory utilization, DIMM status, and timings
- `firmware` — Show firmware version and feature list
- `test` — Run memory diagnostics and bandwidth tests
- `config` — View or modify memory monitor configuration
- `mode` — Switch display mode
- `reboot` — Restart memory monitor controller
- `fold` — Collapse device panel
- `unfold` — Expand device panel
- `toggle` — Toggle device panel visibility
