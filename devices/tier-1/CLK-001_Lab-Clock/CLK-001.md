## Description

Precision laboratory timekeeping device with crystal oscillator, NTP synchronization, and drift compensation. The Lab Clock provides authoritative time references for all laboratory operations, supporting multiple display modes including stopwatch and countdown functionality. It serves as the timing backbone for scheduled processes, experiment duration tracking, and system event coordination.

## Terminal Command

```
clk <status|firmware|test|config|mode|reboot|fold|unfold|toggle>
```

**Aliases**: `clock`

### Subcommands

- `status` — Show clock status, current time, and sync state
- `firmware` — Show firmware version and feature list
- `test` — Run clock accuracy diagnostics
- `config` — View or modify clock configuration
- `mode` — Switch display mode (clock/stopwatch/countdown)
- `reboot` — Restart clock controller
- `fold` — Collapse device panel
- `unfold` — Expand device panel
- `toggle` — Toggle device panel visibility
