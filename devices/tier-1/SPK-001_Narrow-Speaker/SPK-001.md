## Description

Directional audio output device with narrow beam-focus technology for targeted sound delivery in the laboratory environment. The Narrow Speaker provides audio feedback for system events, alarms, and data sonification with precise frequency filtering, volume control, and mute gating capabilities.

## Terminal Command

```
spk [status|power|firmware|test|reset|volume|mute|filter|fold|unfold|toggle|info]
```

**Aliases**: `speaker`, `spk001`, `narrow-speaker`

### Subcommands

- `status` — Show speaker status and audio output state
- `power` — Display power consumption details
- `firmware` — Show firmware version and feature list
- `test` — Run audio diagnostics and speaker tests
- `reset` — Reset audio controller
- `volume` — Adjust output volume level
- `mute` — Toggle mute state
- `filter` — Configure frequency filter parameters
- `fold` — Collapse device panel
- `unfold` — Expand device panel
- `toggle` — Toggle device panel visibility
- `info` — Display detailed device information
