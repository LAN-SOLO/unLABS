## Terminal Command

```
qua [status|power|firmware|test|reset|mode|sensitivity|depth|frequency|fold|unfold|toggle|info]
```

**Aliases**: analyzer, qua001, quantum-analyzer

### Subcommands

- `status` — Show device status
- `power` — Show power consumption
- `firmware` — Show firmware info
- `test` — Run diagnostics
- `reset` — Reset device to defaults
- `mode` — Set analysis mode (e.g., ANOMALY)
- `sensitivity` — Adjust scan sensitivity
- `depth` — Set scan depth
- `frequency` — Set scan frequency
- `fold` — Collapse device panel
- `unfold` — Expand device panel
- `toggle` — Toggle device panel visibility
- `info` — Show device information

## Analysis Modes
