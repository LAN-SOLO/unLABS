## Description

The Quantum Compass is a lightweight navigation instrument combining classical gyroscope and magnetometer sensors with a quantum link for enhanced positional accuracy. It provides anomaly tracking, distance calculation, and needle stabilization for exploration operations. The QCP-001 has the lowest power footprint among Tier 2 devices at just 2.5 E/s full load, making it ideal for extended field operations.

## Terminal Command

```
qcp [status|firmware|test|config|mode|bearing|distance|reboot|fold|unfold|toggle]
```

**Aliases**: compass, qcompass

### Subcommands

- `status` — Show device status
- `firmware` — Show firmware info
- `test` — Run diagnostics
- `config` — View or modify configuration
- `mode` — Switch operating mode
- `bearing` — Display current bearing
- `distance` — Calculate distance to target
- `reboot` — Reboot the device
- `fold` — Collapse device panel
- `unfold` — Expand device panel
- `toggle` — Toggle device panel visibility
