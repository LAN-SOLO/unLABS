## Description

The Interpolator is a medium-class data processing instrument focused on color interpolation, era manipulation, and spectral analysis for crystal trait computation. Its prism array and spectrum lock provide precise optical measurements, while the built-in prediction engine enables forecasting of trait shifts. The INT-001 serves as the foundational device in the Optics tech tree.
