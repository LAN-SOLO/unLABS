## Description

The Anomaly Detector is a medium-class scientific instrument designed for waveform scanning and anomaly detection within the lab environment. It provides signal analysis and frequency sweep capabilities, operating across multiple detection modes. Integrated with the halo-link system for cross-device anomaly correlation, the AND-001 is a core component of the Science tech tree's second tier.
