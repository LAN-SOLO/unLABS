## Description

The Diagnostics Console is a lightweight system-level diagnostic instrument providing comprehensive health monitoring across the entire lab infrastructure. It covers 6 diagnostic categories (SYSTEMS, DEVICES, ENERGY, NETWORK, CRYSTALS, PROCESS) with 36 individual components and configurable scan depth from 0 to 100. The DGN-001 serves as the primary troubleshooting and status reporting tool within the System tech tree.

## Terminal Command

```
dgn [status|power|firmware|test|reset|scan|category|depth|alerts|health|fold|unfold|toggle|info]
```

**Aliases**: diag, dgn001, diagnostics-console

### Subcommands

- `status` — Show device status
- `power` — Show power consumption
- `firmware` — Show firmware info
- `test` — Run diagnostics
- `reset` — Reset device to defaults
- `scan` — Run a diagnostic scan
- `category` — Select diagnostic category
- `depth` — Set scan depth level
- `alerts` — View active alerts
- `health` — Display health summary
- `fold` — Collapse device panel
- `unfold` — Expand device panel
- `toggle` — Toggle device panel visibility
- `info` — Show device information
